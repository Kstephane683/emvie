📘 Guide d'utilisation de votre site

Bienvenue ! Ce guide vous explique comment profiter pleinement de votre nouveau site web EM'VIE SHOP accessible sur https://emvie.shop.

🌐 1. Accéder à votre site

Votre site est en ligne à l'adresse : https://emvie.shop
La première activation peut prendre 10 à 30 minutes après la livraison.

📞 2. Le formulaire de contact

Les messages envoyés via le formulaire arrivent sur votre WhatsApp/e-mail. Pensez à répondre sous 24h pour maximiser votre taux de conversion.

🖼️ 3. Modifier vos images

Les images sont stockées dans le dossier images/optimisees/. Pour les remplacer :

  • Respectez les noms de fichiers existants
  • Format recommandé : WebP ou JPG
  • Taille max conseillée : 1200px de large

🔍 4. Référencement (SEO)

Votre site est optimisé pour Google. Pour améliorer votre classement :

  • Ajoutez votre entreprise sur Google Business Profile
  • Demandez des avis clients sur Google
  • Partagez votre site sur vos réseaux sociaux

📊 5. Suivi des visites

Pour suivre vos visiteurs, connectez Google Analytics ou Plausible. Insérez le code de suivi dans le <head> de chaque page.

🛠️ 6. Maintenance

Pour toute modification (texte, design, nouvelle page), contactez votre agence. N'essayez pas d'éditer le code vous-même sans sauvegarde préalable.
